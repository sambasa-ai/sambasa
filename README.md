# Sambasa

Sambasa is an AI platform built with modern web technologies including Next.js, Tailwind CSS, Shadcn UI, PostgreSQL, Prisma ORM, and Better Auth for secure authentication.

The name derives from the Sanskrit word Saṃbhāṣā (संभाषा), meaning "conversation".
